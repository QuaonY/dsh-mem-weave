# 隐私与安全

记忆是最私人的数据，默认不出本机。本文说明敏感信息怎么处理、权限边界在哪、备份怎么加密，以及需要你自己注意的地方。

## 1. 数据在哪

- 主库是一个 SQLite 文件（默认 `$DSH_HOME/memweave/memweave.db`）；镜像是同目录下的 Markdown，日志在同目录 `logs/`。
- 没有遥测、没有账号、没有云端同步。
- 对外请求只发生在两种情况：你配置了外部 embedding 服务；你下载本地模型权重。两者都可不用。
- 启动时只探测本机 `127.0.0.1` 上的 Ollama / LM Studio（不离开本机），`MEMWEAVE_EMBEDDING_DISCOVERY=0` 可关闭。
- 卸载插件不会删除记忆库；彻底清除需先退出 DSH，再删除整个 `dataDir`（含 `memweave.db`、`mirror/`、`logs/`、`models/`、`backups/`）。

## 2. 敏感信息

**识别范围**：手机号、邮箱、身份证号、信用卡号、密码/凭证、API 密钥（含常见云厂商与平台令牌）、IP 地址、详细地址。规则集可用 `governance.sensitivePatterns` 调整，并支持白名单。

**写入侧**：密钥、令牌、密码在写入阶段直接拦下；其余敏感项按类型标记 `is_sensitive` 并记录置信度。

**读出侧**：召回与注入默认做字段级脱敏（`privacy.recallPolicy: "redact"`），例如手机号只留前三位、邮箱只留首字母与域名；需要更保守时可切 `"filter"`，整条不参与召回与注入。无论哪种策略，**敏感条目都不进向量索引**。

脱敏只发生在「给模型看的边界」：界面里的详情、导出与编辑看到的仍是原文，便于你核对与修正。

## 3. 权限边界

| 操作 | AI（工具调用） | 人（界面） |
| --- | --- | --- |
| 写入普通记忆 | 可提案，低风险自动通过 | 直接写 |
| 写 `soul` / `rules` | 拒绝（`E_PERM`） | 需确认 |
| 改人格 / 应用预设 | 拒绝 | 需确认 |
| 裁决候选与冲突 | 只读 | 唯一执行者 |
| 归档记忆 | 可 | 可，可撤销 |
| 永久删除 | 拒绝 | 需手输确认词 |
| 改数据目录 | 拒绝 | 需确认 |

界面操作在服务端固定以 `human` 身份执行，AI 调用固定以 `agent` 身份执行。设置查询接口（当前值与出厂值）只回脱敏后的配置，不含 `apiKey` 明文。

**这条边界依赖宿主不把本插件的 RPC 暴露给 AI 或其他插件。** 若宿主允许第三方直接调用远程接口，身份字段可以被伪造——部署时应确保只有界面能访问 RPC。

## 4. 注入侧防护

- 注入前清理成对的特殊括号与换行，防止记忆内容伪造段落或指令块；三段分别拼接，缺块不留空行。
- 每轮注入了什么、为什么命中，记录在 `inject_state` 与检索 `trace` 里，可在界面核对。
- 运行日志只记事件、耗时与计数，不记记忆正文；审计记录保留操作类型、时间、标识与差异摘要，界面默认脱敏展示。
- 会话原文索引（`quote`）默认关闭；开启后按 `quote.indexDays`（默认 90 天）保留。
- 轮后通知卡片只带脱敏摘要，且限定本会话，不会带出其他会话的内容。

## 5. 备份

- 全量备份为单文件，可选加密：**AES-256-GCM + scrypt** 派生密钥，旁文件记录 salt 与校验信息。
- 恢复时先校验再解密；篡改、密钥错误、旁文件缺失都会直接失败，不会写进现有库；恢复前自动备份，导入失败整体回滚。
- 旧版 AES-CBC 备份仍可解密，便于升级迁移。

**口令不保存在任何地方。** 忘记口令等于无法恢复加密备份，请自行保存。

## 6. 已知边界

1. 敏感检测是规则 + 置信度，不是 NLP 模型：改写、拆分、编码后的信息可能漏检，重要内容建议自行确认后再让 AI 记住。
2. 脱敏只覆盖已知的八类模式；自定义敏感词需自行配置。
3. 记忆镜像（`mirror/`）是明文 Markdown，任何能读该目录的程序都能读到；不需要时可在配置里关掉。
4. 配置了外部 embedding 服务时，送去向量化的文本会离开本机；不配置则只探测本机 `127.0.0.1`。
5. 本机模型权重从官方源或镜像下载并校验大小与 sha256，仍建议在可信网络下操作。
